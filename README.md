A one-page broadsheet summing up the world's news of Tuesday 24 November 2026,
entered in the [news-image-20261124 bounty](https://make.fun/bounty/news-image-20261124)
on make.fun.

The image leads with the day's two biggest stories — Nvidia reinstating Jensen
Huang as CEO (+31.5% on the day) and COP31 ending with no deal — then six
pictured stories from around the world, and a dense strip of 38 more stories
grouped by region and field: 46 stories in total.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` copies the finished `entry.png` (1024x1024) to the output directory.
